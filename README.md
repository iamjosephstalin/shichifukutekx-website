# ShichifukuTekx Enterprise AI Platform

> **Empowering Dubai & UAE Enterprises with Intelligent AI Solutions.**

![ShichifukuTekx Banner](public/images/og-image.png)

## Overview

**ShichifukuTekx FZE** is a premium enterprise AI solutions provider based in the UAE. This web application serves as the primary digital touchpoint for clients, showcasing expert AI consulting, automation services, and industry-specific intelligence solutions.

The platform is engineered for performance, aesthetics, and user engagement, featuring cinematic animations, deep interactivity, and a futuristic "Cyber-Japan" design language.

## Key Features

- **Cinematic Hero Experience**: A custom-animated introduction sequence with encrypted text decryption effects and parallax scrolling.
- **Interactive "Cyber-Glow" UI**: Buttons, cards, and grid elements feature advanced hover states, neon glows, and magnetic interactions.
- **Performance Optimized**: Built with `Vite` and `React` for instant load times, utilizing `Lenis` for silky-smooth smooth scrolling.
- **Responsive Design**: Fully optimized for mobile, tablet, and ultra-wide desktop displays.
- **SEO Ready**: configured with distinct meta tags, Open Graph data, and semantic HTML structure for maximum visibility in the GCC region.

## Technology Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) (Custom "Obsidian" & "Neon" Theme)
- **Animations**:
  - [GSAP](https://greensock.com/gsap/) (ScrollTrigger, Timelines)
  - [Framer Motion](https://www.framer.com/motion/) (Component Transitions, Gestures)
- **Scrolling**: [Lenis](https://github.com/studio-freight/lenis) (Virtual Scroll)
- **Icons**: [Lucide React](https://lucide.dev/)

## Project Structure

```bash
├── components/
│   ├── layout/       # Navbar, Footer, Cursor, Layout wrappers
│   └── ui/           # Reusable UI components (Buttons, Cards, Effects)
├── pages/            # Page-level components (Home, Services, Contact)
├── public/           # Static assets (images, logos)
└── src/              # Entry points and global styles
```

## Getting Started

1.  **Install Dependencies**
    ```bash
    npm install
    ```

2.  **Run Development Server**
    ```bash
    npm run dev
    ```

3.  **Build for Production**
    ```bash
    npm run build
    ```
